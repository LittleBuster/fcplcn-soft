# FCPLCn Chart Sans

Шрифт для растровых графиков на хабе содержит поднабор латиницы и кириллицы
из Noto Sans Regular. Имя семейства изменено на FCPLCn Chart Sans.
Исходный шрифт и производный поднабор распространяются по SIL Open Font License 1.1.
[Noto Sans Regular, исходный файл](https://github.com/notofonts/noto-fonts/blob/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSans/NotoSans-Regular.ttf) · [Лицензия](OFL.txt)
