# FCPLCn: host-тесты авторизации

Из корня проекта:

```sh
tools/firmware/test-base-auth
```

Команда собирает **настоящий `main/security/auth.cpp`** отдельно от ESP-IDF, включает ASan/UBSan и запускает два случая CTest: полный жизненный цикл авторизации и отказ при повреждённой записи NVS. Требуются CMake, Ninja, Clang/GCC с C++17 и OpenSSL 3+. На текущем Mac они установлены. При необходимости задайте `OPENSSL_ROOT_DIR`; артефакты находятся в локальном `.build/` и игнорируются Git. Дополнительные аргументы команды передаются CTest.

Стенд проверяет начальные `admin`/пустой пароль, salted PBKDF2, UTF-8/размеры, cookie-флаги и lifetime, смену/очистку пароля, переименование в UTF-8 и вход с новым именем, инвалидирование и лимит сессий, logout, expiry, backoff и ошибки записи. Часы управляются тестом, поэтому ожидания на восемь часов или sleep не нужны.

Подменены только платформенные API: HTTP-запрос/response header, RAM-модель NVS, время и генератор случайных байтов. PSA-адаптер выполняет реальный PBKDF2-HMAC-SHA256 через OpenSSL и проверяет порядок параметров. Это не запуск target-реализации mbedTLS/PSA; её включение дополнительно проверено по реальным compile commands ESP-IDF.

Модель NVS воспроизводит API-успех/ошибку, а не физическую запись Flash и перебои питания. Детерминированный генератор нужен для тестовых токенов и не проверяет энтропию ESP32. Стенд не проверяет LAN/TLS, CSRF/Origin в HTTP-роутах, задержку PBKDF2 и watchdog на S3. Никаких GPIO, перезапуска или прошивки контроллера команда не выполняет.
